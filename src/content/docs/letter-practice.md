## Stroke order

Every character has an animated stroke-order guide. Stroke order is worth
learning early: it makes handwriting legible and makes characters easier to
recall.

## Drawing

Trace a character and the app checks the shape you produced rather than only
the final image, so a character drawn in the wrong order is caught.

## Reading drills

Alongside handwriting, quick recognition drills mix similar-looking characters
together, which is where most early confusion happens.
