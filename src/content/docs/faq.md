## Is it free?

Yes. The app is free to use and the source is MIT licensed.

## Do I need an account?

Not to try a lesson. You need one to save progress across sessions and
devices.

## Can I self-host it?

Yes. The source is public and the repository documents how to run the app and
its backend yourself.

## Can I contribute?

Yes — course content, translations, and code. Open an issue on GitHub
describing what you want to work on before starting anything large.

## Which languages are supported?

Korean, Japanese, and Spanish today. See the roadmap for what is queued.
