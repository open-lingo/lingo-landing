## Who it is for

If you are starting a language from zero, skip the placement test — the first
module assumes no prior knowledge and the test will only tell you what you
already suspect.

It is worth taking if you have studied the language before, even informally.
It finds the point where the course stops being review and starts being new.

## How it works

The test runs in two stages. First it asks a handful of questions spread
across the whole course to estimate roughly where you sit. Then it asks a
focused set around that estimate to pin it down.

It is short by design. It is not an exam, and there is no score to beat.

## What happens to the modules you pass

Passed modules unlock, so you can move straight to the first thing you have
not covered. The vocabulary from those modules is added to your review queue
rather than marked as finished — you will see each word once before the
scheduler starts spacing it out.

That is deliberate: passing a question about a word proves recognition, not
that the word will still be there next week.

## Testing out of a single module

You do not have to decide everything up front. Any module can be tested out of
individually from the course map, which is the better tool once you are
already partway through.
